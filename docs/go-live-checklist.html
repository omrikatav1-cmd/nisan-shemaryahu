ניסן — בדפדפן שלו, על המייל שלו ניסן

רכישת הדומיין nisan-shemaryahu.co.ilאצל רשם מוסמך של איגוד האינטרנט הישראלי (למשל LiveDNS או Domain The Net). ~80–100 ₪ לשנה. הדומיין נרשם על שם ניסן, בחשבון שלו — הנכס שלו.
פתיחת חשבון Supabase — חינם, לא קונים כלוםב-supabase.com עם המייל של ניסן → פרויקט חדש (Region: פרנקפורט — הקרוב לישראל) → SQL Editor → מדביקים את כל תוכן docs/supabase-setup.sql → Run. זה יוצר את טבלת הלידים + אבטחת RLS. ה-Free tier מכסה טבלת לידים בקלות רבה.
העברת מפתחות Supabase לעומרי — לא בצ'אטSettings → API: להעתיק Project URL + anon key + service_role key ולשלוח לעומרי בערוץ פרטי. עומרי מזין אותם ישירות ל-Vercel (פקודות מוכנות בסעיף 2) — המפתחות לא עוברים דרך קלוד.
וואטסאפ עסקילהוריד WhatsApp Business ולהחליט: אותו מספר (הפרופיל האישי הופך לעסקי) או SIM/מספר חדש. זה המספר שכל ה-CTA-ים באתר יפנו אליו — כרגע הם על המספר האישי.
חשבון Google Ads על שם ניסן + אמצעי תשלוםעם חשבון גוגל של העסק. את ה-GA4/GTM פותח ניסן או אדיר — מה שצריך בסוף זה מזהה קונטיינר GTM-XXXXXXX אחד. הצעדים המלאים: docs/campaign-launch-guide.html.
כרטיס Google Business Profileעסק מבוסס-אזור-שירות (בלי כתובת גלויה): קטגוריה ראשית "מנעולן", אזור שירות אור יהודה + ~15 ק"מ, טלפון = המספר העסקי, אתר = nisan-shemaryahu.co.il. האימות של גוגל (וידאו/גלויה) לוקח כמה ימים — לפתוח מוקדם.
תיאום יום צילום עם ללב מדיהתמונות פנים, רכב, ציוד — מחליפות את תמונות הסטוק ב-hero ומזינות OG ממותג. הפריט התוכני האחרון שנשאר.
רשימת 10–15 לקוחות עבר (שם + טלפון)לבקשות ביקורת גוגל אמיתיות (Review Engine מנסח אישית). סקשן הביקורות באתר נשאר מוסתר עד שיש אמיתיות — לעולם לא מפוברקות.

עומרי — קליקים שרק הוא יכול עומרי

אישור Vercel↔GitHub App (קליק אחד)Vercel Dashboard → Project → Settings → Git, או מסך התקנת האפליקציה בגיטהאב, עבור omrikatav1-cmd/nisan-shemaryahu. משחרר auto-deploy ל-plumbing/handyman (כרגע redeploy ידני בלבד; vercel git connect מחזיר 400 עד האישור).
חיבור הדומיינים ב-Vercelבכל פרויקט: Settings → Domains → Add לפי טבלת סעיף 0 (root + www למנעולן, סאב לכל אחד מהשניים) → מגדירים אצל הרשם את רשומות ה-DNS בדיוק כפי ש-Vercel מציג. SSL אוטומטי.
הזנת מפתחות Supabase ל-Vercel (בלי לעבור דרך צ'אט)מתוך ה-worktree, פעם אחת לכל אחד משלושת הפרויקטים: npx vercel env add NEXT_PUBLIC_SUPABASE_URL production וכן NEXT_PUBLIC_SUPABASE_ANON_KEY + SUPABASE_SERVICE_ROLE_KEY (הערכים מודבקים בטרמינל כשהפקודה מבקשת). לחלופין: לתת לקלוד אישור מפורש והוא מריץ, עם הערכים מקובץ מקומי.
אישור לקלוד: env של דומיין + GTM ו-redeployכתיבת env vars ב-Vercel חסומה לקלוד בלי אישור מפורש (gotcha מתועד). ברגע שיש דומיין + GTM-XXXXXXX — אישור אחד וקלוד סוגר את סעיף 3 כולו.

קלוד — אוטומטי ברגע שהקלטים קיימים קלוד

עדכון SITE_URL פר-פרויקט + NEXT_PUBLIC_GTM_IDשלושה ערכי SITE_URL לפי טבלת סעיף 0, ומזהה ה-GTM על שלושת הפרויקטים. NEXT_PUBLIC_* נצרב בזמן build — מחייב redeploy.
Redeploy לשלושת האתריםnpx vercel deploy --prod --yes מה-worktree למנעולן; plumbing/handyman דרך clone+link כמתועד ב-memory.md — או auto-deploy אם ה-GitHub App אושר.
Google Search Console — Domain property אחתאימות TXT אחד ב-DNS מכסה את ה-root וכל הסאבים. הגשת שלושת ה-sitemaps.
בדיקת קצה-לקצה (סעיף 5)טופס → Supabase → דשבורד; GTM Preview; sitemap/robots/OG על הדומיין החדש.
עדכון 3 קבועי הטלפון כשהוואטסאפ העסקי נפתחOWNER_PHONE_INTL / OWNER_PHONE_DISPLAY / OWNER_PHONE_HREF ב-lib/siteConfig.ts — שינוי קוד יחיד בכל התוכנית.

שער הקמפיינים — מה חוסם עליית מדיה

  • ארבעה תנאים, כולם חובה: דומיין חי ✕ טופס שומר בפועל ל-Supabase של ניסן ✕ GTM יורה (lead_form_submit + קליקי טלפון/וואטסאפ) ✕ מספר וואטסאפ עסקי באתר.
  • רק אז בונים קמפיינים — הקופי, מילות המפתח והמבנה כבר מוכנים: docs/campaign-packages.md + docs/google-ads-market-and-abc-plan.md. תקציב מדיה מתוכנן ~2,500 ₪/חודש.
  • Search בלבד — LSA (Local Services Ads) לא זמין בישראל (נבדק ותועד).
  • תזכורות ציות שחלות גם על המודעות: אין הבטחות זמן הגעה, אין "ביטוח", אין "מוסמך" ליד אינסטלציה עד שהתעודה מגיעה.
